<div class="card" id="core-idea">
  <h2>Core Idea</h2>
  <p>This is not a feed. It is not a blog. It is not a set of opinions. It is a reference point — something you come back to when your situation changes, or when things start to feel unclear. A page should still work when you come back to it later. Not because it changed. Because you did.</p>
</div>

<div class="card" id="the-process">
  <h2>How It Works</h2>
  <ol>
    <li><strong>Locations stay fixed.</strong> You know where things are.</li>
    <li><strong>Names stay recognizable.</strong> Definitions stay steady.</li>
    <li><strong>Pages connect.</strong> When one thing becomes unclear, another helps you see it again.</li>
    <li><strong>Meaning deepens.</strong> The same page can mean more over time without becoming something new.</li>
  </ol>
</div>

<div class="card" id="why-it-matters">
  <h2>Why It Matters</h2>
  <p>Most things are built to be consumed once. If something matters, it should still be there later. A good reference is easy to return to — you should not have to search for what helped you before. That is what turns this into a system instead of a collection.</p>
</div>

<div class="card" id="failure-mode">
  <h2>Failure Mode</h2>
  <strong>Treating it like content to scroll through</strong>
  <p>If you read a page once and move on, it becomes a feed. The value is in the return — letting the same page meet you in a different situation, with a different need.</p>
</div>

<div class="card" id="practice">
  <h2>Practice</h2>
  <p>When things start to drift, ask:</p>
  <ul>
    <li>What do I need to return to right now?</li>
    <li>Which page named this last time?</li>
    <li>What did I understand here that I have stopped using?</li>
  </ul>
</div>
