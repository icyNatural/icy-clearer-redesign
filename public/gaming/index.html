Local controls

Your evaluations stay in this browser and origin. file://, localhost:3000, 127.0.0.1 and other ports do not share data. Use localhost:3000 consistently after recovery.
Back up regularly with Export Data and keep the downloaded JSON outside this site. Before importing, a target backup is downloaded and source/target snapshots are verified in browser storage. Exact duplicate IDs are skipped; differing records with the same ID stop the import without overwriting. File attachments export references, not playable file bytes: retain original media separately.
